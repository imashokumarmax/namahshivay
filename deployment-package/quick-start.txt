🚀 FASTEST WAY TO DEPLOY (5 MINUTES):
─────────────────────────────────────────────────────────────────

1. LOGIN TO HOSTINGER
   → Go to: https://hpanel.hostinger.com
   → Login with your credentials
   → Click on your domain: ncr-dreamhomes.com

2. OPEN FILE MANAGER
   → In cPanel, find "File Manager" icon
   → Click to open

3. GO TO public_html
   → Click on "public_html" folder
   → ⚠️ BACKUP EXISTING FILES FIRST!
   → Select all files → Download (save as backup)
   → Delete all old files

4. UPLOAD THIS ZIP FILE
   → Click "Upload" button (top right)
   → Select: ncr-dreamhomes-deployment.zip
   → Wait for upload to complete (190 KB - takes few seconds)

5. EXTRACT THE ZIP
   → Right-click on ncr-dreamhomes-deployment.zip
   → Select "Extract"
   → Extract to: /public_html/

6. MOVE FILES TO ROOT
   → Open the "build" folder
   → Select ALL files inside build/
   → Move them to public_html/ (root directory)
   → Delete empty "build" folder
   → Delete the ZIP file

7. VERIFY .htaccess
   → In public_html/, you should see .htaccess file
   → If you don't see it:
     - Click Settings (top right)
     - Check "Show Hidden Files"

8. TEST YOUR WEBSITE
   → Open browser
   → Visit: https://ncr-dreamhomes.com
   → Check all pages work:
     ✓ Home page
     ✓ /noida
     ✓ /ghaziabad
     ✓ /greater-noida
     ✓ /greater-noida-west
     ✓ /jewar-airport

🆘 TROUBLESHOOTING:
─────────────────────────────────────────────────────────────────

Solution: Make sure .htaccess file is uploaded

Problem: Styles not loading (plain white page)
Solution: Clear browser cache (Ctrl + Shift + Delete)

Problem: Can't see .htaccess file
Solution: Settings → Show Hidden Files (ON)

Problem: HTTPS not working
Solution: In cPanel → SSL/TLS → Run AutoSSL
