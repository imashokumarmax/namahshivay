🎯 STEP-BY-STEP DEPLOYMENT INSTRUCTIONS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: DOWNLOAD DEPLOYMENT FILES
──────────────────────────────────
You need to download these files from the server:

1. Build folder: /app/frontend/build/
2. .htaccess file: /app/deployment-package/.htaccess
3. README.md: /app/deployment-package/README.md

OR

Download the complete package:
/app/deployment-package/ncr-dreamhomes-deployment.zip


STEP 2: CREATE ZIP FILE (EASIER UPLOAD)
────────────────────────────────────────
If not already zipped, compress the build folder:
- Right-click 'build' folder → Compress → Create ZIP


STEP 3: ACCESS HOSTINGER CPANEL
────────────────────────────────
1. Login to https://hpanel.hostinger.com
2. Find your domain: ncr-dreamhomes.com
3. Click "Manage" next to your domain
4. Click "File Manager" icon


STEP 4: NAVIGATE TO PUBLIC_HTML
────────────────────────────────
1. In File Manager, click "public_html" folder
2. ⚠️ IMPORTANT: Backup existing files first!
   - Select all files → Download → Save backup
3. Delete all old files in public_html


STEP 5: UPLOAD YOUR WEBSITE
────────────────────────────
METHOD A - Upload ZIP (Recommended):
1. Click "Upload" button in top right
2. Select your build.zip file
3. Wait for upload to complete
4. Right-click build.zip → Extract
5. Move all files from 'build/' folder to public_html/
6. Delete empty 'build' folder and build.zip

METHOD B - Upload Individual Files:
1. Click "Upload" button
2. Upload all files from build/ folder
3. Upload .htaccess file separately


STEP 6: UPLOAD .HTACCESS FILE
──────────────────────────────
1. Make sure .htaccess is in public_html/ root
2. If you don't see it, enable "Show Hidden Files":
   Settings → Show Hidden Files (ON)
3. Verify .htaccess content matches provided file


STEP 7: SET CORRECT PERMISSIONS
────────────────────────────────
1. Select all files in public_html
2. Right-click → Permissions
3. Set files to 644
4. Set folders to 755


STEP 8: VERIFY FILE STRUCTURE
──────────────────────────────
Your public_html should look like:

public_html/
├── index.html          ← Main file
├── .htaccess          ← Apache config
├── manifest.json
├── robots.txt
├── asset-manifest.json
├── static/
│   ├── css/
│   │   └── main.3b3756fc.css
│   └── js/
│       └── main.cd3796dd.js


STEP 9: TEST YOUR WEBSITE
──────────────────────────
1. Visit https://ncr-dreamhomes.com
2. Test these pages:
   - Home: https://ncr-dreamhomes.com/
   - Noida: https://ncr-dreamhomes.com/noida
   - Ghaziabad: https://ncr-dreamhomes.com/ghaziabad
   - Greater Noida: https://ncr-dreamhomes.com/greater-noida
   - Greater Noida West: https://ncr-dreamhomes.com/greater-noida-west
   - Jewar Airport: https://ncr-dreamhomes.com/jewar-airport

3. Test on mobile device
4. Check WhatsApp button works
5. Verify phone number link works


STEP 10: FORCE HTTPS (IMPORTANT!)
──────────────────────────────────
1. In cPanel, go to "SSL/TLS Status"
2. Make sure SSL is enabled for ncr-dreamhomes.com
3. If not, click "Run AutoSSL"
4. Wait for certificate installation

Problem: "404 Not Found" on page refresh
Solution: Make sure .htaccess is uploaded and mod_rewrite is enabled

Problem: Styles not loading (plain text)
Solution: Check file permissions (644 for files, 755 for folders)

Problem: Images not showing
Solution: Clear browser cache, check image paths

Problem: HTTPS not working
Solution: Enable SSL in cPanel → SSL/TLS Status → Run AutoSSL

Problem: "File not found" errors
Solution: Verify all files from build/ are in public_html/ root

Problem: Admin panel shows error
Solution: Expected - admin panel needs backend (not on cPanel)
